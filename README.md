# ENGM2283 Project

## Description
This project is a group engineering data structures and algorithms project for ENGM2283
The goal is to implement a project of our choosing that contains minimum four classes,
with at least one being inherited from base and one being composition.
Lastly these classes must be put into a linked list that can 
- Store
- Retrieve
- Search
- Sort
- Delete
- Count
- Empty
- Clear
  
## Features
- Prompts user to modify a database of real estate properties, in which they can choose the above options.

## Setup
1. Clone the repo
2. Open the solution file in visual studio
3. build the project
   
## Usage
1. Run the program in visual studio
2. Follow program instructions in the console
